# Analysis-output retention policy

The repository-local `analyses/` directory holds expensive or downstream-
required artifacts, not every table produced by the notebook.

## Retention rule

Save an output here only when it is expensive to recreate, required by a later
analysis step, or a durable quality-control audit. Easily regenerated
descriptive/statistical tables should be generated by the notebook when
needed, rather than retained. Every retained artifact must live in a documented
subfolder.

## `qc/`

Full-cohort longitudinal EEG preprocessing audit, retained because it requires
filtering and epoching every eligible run.

- `longitudinal_preprocessing_qc_subjects.csv` — final per-participant status.
- `longitudinal_preprocessing_qc_runs.csv` — run-level Status, epoch, and
  baseline checks.
- `longitudinal_preprocessing_qc_failures.csv` — strict QC exceptions needing
  follow-up.

## `eeg_pd/cluster_permutation/`

Retained 10,000-permutation Pd cluster-test results.

- `training_pd_pre_post_cluster_permutation_clusters.csv` — FWER-corrected
  cluster results.
- `training_pd_pre_post_cluster_permutation_pointwise_statistics.csv` —
  pointwise statistics and cluster membership.

## `session5_feature_references/`

Reserved for the compact, frozen Session-5 top-30 reference artifacts needed
for longitudinal feature tracking:

- `session5_reference_summary.parquet`
- `session5_reference_clean_trials.parquet`
- `session5_reference_top30.parquet`
- `session5_reference_settings.json`
- `session5_reference_build_log.parquet` — checkpointed per-participant,
  per-decoder build status, selected pruning iteration, CV AUPRC, and any
  failure message. Retained as the model-selection audit trail.
- `transforms/{subject_id}_{decoder_side}_frozen_reference.npz` — one compact
  right and left transform per participant. Each contains the final
  Session-5 xDAWN filters, epoch-time and resampling indices, z-score means
  and standard deviations, selected feature indices, and channel order. These
  transforms must be applied unchanged to Session-1 training and decoding-run
  data; they must not be refit during longitudinal evaluation.
